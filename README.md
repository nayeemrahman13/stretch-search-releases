# Stretch Search

Turn highlighted text into a learning map on your Mac. Highlight a topic, press **⇧⌘L**, and explore the explanation or ask a follow-up question.

[Download Stretch Search](https://github.com/nayeemrahman13/stretch-search-releases/releases/latest/download/StretchSearch.zip) · [Release notes](https://github.com/nayeemrahman13/stretch-search-releases/releases/latest)

Requires an Apple silicon Mac running macOS 14 or later. Releases are signed and notarized.

## Install

1. Download the ZIP and unzip it.
2. Move `StretchSearch.app` to Applications and open it.
3. Follow setup to enable Accessibility, then highlight a topic and press **⇧⌘L**.

The app lives in the menu bar. Click its icon to reopen the learning panel; right-click it for Settings and update checks. The default AI provider needs no API key.

## Updates

Version 1.1.0 and later can update inside the app. Choose **Check for Updates…** in the menu bar or open **Settings → Updates**. Daily checks default on; automatic downloads are optional.

If you have an older version, quit it and replace the app in Applications once. Future updates can be installed inside the app. Your settings and learning history are preserved.

This repository contains app downloads and the signed automatic-update feed.
